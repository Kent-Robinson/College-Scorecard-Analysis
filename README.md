# College-Scorecard-Analysis
Multivariate statistical analysis of 6,000+ U.S. higher education institutions using the U.S. Department of Education's College Scorecard dataset. Applied Principal Component Analysis (PCA) to reduce 8 institutional variables — including admissions selectivity, cost of attendance, Pell Grant recipients, graduation rates, and post-graduation earnings — into interpretable dimensions. Used K-means clustering (K=5) to identify distinct institutional archetypes, and Linear Discriminant Analysis (LDA) to classify institutions by control type (public, private nonprofit, private for-profit), achieving 94.5% out-of-sample accuracy on an 80/20 train-test split. Analysis conducted in R.
